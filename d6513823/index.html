Datenschutzhinweis zu dieser App

Testfassung über Apple TestFlight · Stand: 25.11.2026

Die App ist für Mitarbeiter eines Autohauses: Fahrzeuge und Unterlagen aufnehmen. Ohne Kopplung mit dem Server des Autohauses arbeitet sie mit Beispieldaten.

  • Kamera: Fahrzeugfotos und Dokumente werden mit der Kamera aufgenommen. Die Texterkennung läuft auf dem Gerät.
  • Server des Autohauses: Erst nach einer Kopplung mit einem Code des Autohauses gehen Aufnahmen und Messwerte an dessen eigenen Server, nicht an Dritte.
  • Lokales Netz: Die App verbindet sich mit dem Server des Autohauses. In der Testfassung kann die Messreihe außerdem eine Ansicht im eigenen WLAN bereitstellen, damit ein Rechner im selben Netz mitschauen kann.
  • Update-Hinweis: Die App fragt regelmäßig beim Testserver nach, ob es eine neuere Fassung gibt. Gesendet wird dabei nur die Kennung der App; am Server fallen übliche Verbindungsdaten an (IP-Adresse, Zeitpunkt).
  • Kein Konto beim Entwickler, keine Bankfunktionen in dieser Fassung.
  • Keine Werbung, kein Tracking, keine Analyse-Dienste von Dritten.
  • TestFlight: Apple kann bei der Verteilung Absturzberichte, Nutzungsdaten und das Feedback erheben, das Sie selbst in TestFlight senden. Dafür gilt die Datenschutzerklärung von Apple.
  • Wenn Sie die App löschen, sind auch die Daten weg, die sie auf Ihrem Gerät gespeichert hat.

Verantwortlich für die Testfassung: Sebastian Lotz. Fragen zum Datenschutz senden Sie bitte über die Feedback-Funktion in TestFlight.
